# Valorum

**A spreadsheet that goes beyond the grid.**

Valorum is a modern spreadsheet application built for more than calculations. It combines a full spreadsheet workspace, a built-in Word-style document editor, advanced data tools, and optional financial-analysis capabilities — all inside one integrated app.

## Spreadsheet

Work with a familiar spreadsheet environment for everyday analysis, modeling, data organization, and more advanced workflows.

Valorum includes:

- Formulas and functions
- Tables and PivotTables
- Charts and visualizations
- Rich cell formatting
- Conditional formatting
- Data validation
- Named ranges
- Sorting and filtering
- Advanced formula tools
- Excel workbook import and export
- Productivity and editing tools

At its core, Valorum remains a general-purpose spreadsheet and can be used completely independently of its financial features.

## Documents & Rich Text Editor

Valorum also includes a built-in **Word-style document editor** for writing alongside your spreadsheets.

Instead of switching between a spreadsheet application and a separate word processor, you can create both spreadsheets and text documents inside the same workspace.

Use the document editor for:

- Reports
- Memos
- Research notes
- Written analysis
- Financial commentary
- Project documentation
- General-purpose documents

The editor provides familiar rich-text capabilities such as:

- Headings and paragraphs
- Bold, italic, underline, and text formatting
- Lists
- Tables
- Images
- Page layout
- Headers and footers
- References and links
- Comments
- Document export

Documents can also stay connected to your spreadsheet work. Values, tables, charts, and other outputs from your sheets can be reused in documents without constantly copying and pasting between separate applications.

**Analyze in the spreadsheet, then explain and present your work in a document — all without leaving Valorum.**

## Financial Data

Valorum can optionally connect financial and market data directly to the spreadsheet.

Financial-data tools can be used for:

- Company fundamentals
- Income statements
- Balance sheets
- Cash-flow statements
- Historical financial metrics
- Market data
- Company comparisons
- Financial research
- Comparable-company analysis

Financial data can be inserted directly into spreadsheet models rather than manually copying information from external sources.

These features are optional. Users who simply want a spreadsheet or document editor never need to use the financial functionality.

## Valuation & Analysis

Valorum can also be used to build professional financial models and valuation workflows directly inside the spreadsheet.

Examples include:

- Discounted Cash Flow (DCF)
- Comparable-company analysis
- Normalized cash-flow / CCF valuation
- WACC analysis
- Financial forecasting
- Historical performance analysis
- Scenario and sensitivity analysis
- Company comparisons

Because the financial data, spreadsheet model, and written analysis can all live in Valorum, the entire workflow can remain connected.

## One Workspace

Valorum is designed around the idea that spreadsheet work often extends beyond the spreadsheet itself.

Instead of constantly moving between a spreadsheet, a word processor, and external data tools, Valorum brings those workflows together.

**Spreadsheet + Word-style documents + connected data, all in one workspace.**

Analyze in the spreadsheet.  
Write in the document editor.  
Connect the data you need.
